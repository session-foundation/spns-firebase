# Session Push Notification Server - Firebase notifier

This is the Firebase notifier plugin for the [Session Push Notification
Server](https://github.com/session-foundation/session-push-notification-server) that allows the SPNS
to interface with FCM servers to deliver push notifications via HTTP2 requests to the Firebase FCM
HTTP v1 API.

The code is written in C++ with various dependencies Session project and other external dependencies
(see `CMakeLists.txt`).
